# AI_LOG

Исходный проект был подготовлен с помощью ChatGPT в чате «Как себя представить».
Текущая проверка и доработка выполнены ассистентом Codex/OpenAI. Точный идентификатор
модели интерфейс инструментов этой сессии не сообщает. Участие ИИ не скрывается:
ассистент читал ТЗ, изучал и изменял код, добавлял тесты, запускал проверки и писал документацию.

Контекст: оригинальный трёхстраничный PDF и ZIP получены из прежнего чата через браузер.
Ключевые задачи для ассистента ниже - краткое разбиение одного реального запроса
пользователя, а не выдуманные отдельные сообщения:

1. «Полностью сверь каждый обязательный пункт ТЗ и бонусы, изучи код, исправь несоответствия».
2. «Запусти тесты, проверь запуск, сделай минималистичную понятную архитектуру».
3. «Готовые README с командами и curl-примерами и честный AI_LOG.md», финальный ZIP,
   таблица соответствия и вопросы для защиты.

Что было слабым и как проверено: исходные зависимости имели широкие диапазоны,
бонусы отсутствовали, README давал Bash-примеры без полноценного варианта для PowerShell.
Версии зафиксированы, добавлены HMAC, фильтры, Alembic, Compose, CI и правила AGENTS.md.
Сохранены четыре небольших модуля приложения; дополнительных сервисных слоёв нет.
При добавлении тестов фикстуры сначала оставались в одном тестовом модуле; они вынесены
в conftest.py для общего использования. Инструменты выявили и исправили порядок импортов
и форматирование. Зависание TestClient оказалось ограничением локальных сокетов в
Windows-песочнице; это установлено по стеку asyncio, а не исправлением бизнес-логики.

Фактически выполнено: 66 тестовых случаев прошли, ruff прошёл, проверены миграции,
реальный Uvicorn, curl, перезапуск и подпись точных байтов тела. Подробности и ограничения
в VERIFICATION.md. Docker Engine недоступен, удалённый GitHub Actions не запускался.
Прежние записи AI_LOG о конкретной модели и ошибках первой генерации независимо
не подтверждены, поэтому не выдаются за наблюдения этой сессии. Самостоятельное
понимание кода кандидатом этими проверками не подтверждается: его нужно показать на созвоне.

Повторная приёмка по запросу пользователя: проект отдельно распакован из финального ZIP, добавлены 55 тестовых случаев. Итог: 121 passed, 0 пропусков; ruff и настоящий запуск с curl прошли. Код приложения при повторной приёмке не изменялся. Docker Engine по-прежнему недоступен; удалённый Actions не запускался.


По просьбе пользователя добавлен START.cmd: локальная подготовка окружения и запуск двойным щелчком. В архив не включаются виртуальное окружение, база и секреты.
