# AI_LOG

Использовал ChatGPT и Codex при подготовке проекта.

ChatGPT помог подготовить исходный вариант API. Codex проверил решение по ТЗ, доработал код, добавил тесты и подготовил документацию и итоговый архив для загрузки на GitHub.

Основные задачи ассистенту:

- Сверить обязательные требования и бонусы с кодом.
- Проверить расчёты, повторные запросы и переходы статусов.
- Запустить тесты, проверить запуск и подготовить инструкции.

В исходном варианте отсутствовали бонусные возможности, а инструкции запуска требовали уточнения для Windows. При доработке добавлены проверка подписи вебхука, фильтры платежей, миграции и конфигурации Docker и GitHub Actions.

При проверке ассистентом прошёл 121 тест, выполнены проверки кода и запросы к запущенному серверу. GitHub Actions успешно прошёл на Python 3.11 и 3.12. Docker-контейнер не проверен. Локально я запустил проект и проверил получение тарифов через Swagger.
